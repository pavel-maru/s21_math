# s21_math

Реализация собственной версии стандартной библиотеки `math.h` на языке C (C11).

## Сборка

    make            # статическая библиотека s21_math.a
    make test       # unit-тесты (Check)
    make gcov_report # html-отчёт покрытия
    make clean      # очистка артефактов

## Реализованные функции

`abs`, `acos`, `asin`, `atan`, `ceil`, `cos`, `exp`, `fabs`, `floor`,
`fmod`, `log`, `pow`, `sin`, `sqrt`, `tan`.

Все функции имеют префикс `s21_` и используют `long double` для расчётов.
Стандартная `math.h` не используется внутри библиотеки — только в тестах.
